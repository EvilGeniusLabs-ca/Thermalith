`Niimbot.Net` is the standalone C# protocol + transport library for NIIMBOT thermal printers (GPL-3.0),
independent of any UI or label engine. Thermalith is its first consumer.

## Added

- **`NiimbotTrace`** (`Niimbot.Net.Diagnostics`) — an opt-in, dependency-free diagnostic sink. Set
  `NiimbotTrace.Sink` to an `Action<string>` and the library traces the connection conversation: port
  enumeration, serial open/read/write (as hex), the probe, and command send/timeout. Leave the sink null
  (the default) and it's near-free — the instrumentation can stay on the hot path.
- Trace points across `SerialPortEnumerator`, `SerialTransport`, `PrinterProbe`, and `NiimbotClient`,
  so a "printer not detected" report can be diagnosed from a captured log — whether the port enumerated,
  opened, what bytes were sent, and what came back.

## Notes

- Additive and backward-compatible: no existing API changed, and the print paths are byte-for-byte
  identical to 1.1.0. The only new surface is the `NiimbotTrace` hook.
