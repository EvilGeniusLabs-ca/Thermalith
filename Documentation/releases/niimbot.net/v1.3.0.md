`Niimbot.Net` is the standalone C# protocol + transport library for NIIMBOT thermal printers (GPL-3.0),
independent of any UI or label engine. Thermalith is its first consumer.

## Fixed

- **Printer resolution was derived from the wrong field, inventing a 229 dpi that does not exist.**
  `PrinterCatalogImporter` read NIIMBOT's `paccuracy` (an internal code, only ever 8 or 9) as if it
  were pixels-per-mm and scaled it by 25.4. For every 300 dpi printer that produced 228.6, rounded to
  229, along with a printhead roughly 76% of its true pixel width - so a caller rendering at the
  reported dpi got output about a quarter too small.

  The dpi actually lives in a separate field, **`paccuracyName`** ("203" or "300" - the only two
  values across all 79 devices). Pixels-per-mm is now a lookup off that (203 -> 8, 300 -> 11.81) and
  `printheadPx = ceil(widthSetEnd x ppmm)`.

## Changed

- **The bundled `printers.json` baseline is regenerated: 22 of 79 entries have corrected `dpi` and
  `printheadPx`.** Affected models include B21 Pro, B1 Pro, B2 Pro, B32/B32R, A1 Pro, A63, C1, D11 Pro,
  EP1C, EP2M_H, EP3M, M2_H, M3, P1, P18, P1S, T8, T8S, TP2M_H, Z401 and B4 Pro. All 203 dpi models,
  including the hardware-verified B1, B4 and B3S_P, are unchanged.

  **If you read `Dpi` or `PrintheadPx` off the catalogue, the values you get back for those models
  change with this version.** That is the point of the fix, but it is a behaviour change rather than a
  pure internal correction, which is why this is a minor bump and not a patch.

## Notes

- No API changed. The print paths are byte-for-byte identical; only the catalogue data and the
  importer's derivation differ.
- The corrected rule reproduces the D11_H's hardware-verified 300 dpi / 142 px on its own - that unit
  had been hand-patched in the baseline earlier, which turned out to be the first sighting of this
  same bug.
- Guarded by tests: the importer mapping (including a fallback for records missing `paccuracyName`)
  and a catalogue invariant asserting no entry carries a dpi outside {203, 300}.
