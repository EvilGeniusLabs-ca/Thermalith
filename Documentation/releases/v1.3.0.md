A fixes release, built mostly from your reports. The B1 Pro stops hanging after a print, third-party label rolls print, Linux gets working emoji and file dialogs, and text gets an inverted style.

## Highlights

- **Inverted text.** Text elements have a fourth style button next to Bold, Italic and Underline that fills the text box black and prints the text white. With Auto-size on, the black box hugs the letters; turn Auto-size off and make the box bigger if you want a margin. Asked for in #22.
- **The B1 Pro no longer hangs after printing.** The label printed, but the app stayed on "Printing" and the printer had to be unplugged before the next job. thujones tracked down both causes and posted the fix in #21.
- **Third-party and used-up rolls print.** A roll whose RFID tag the printer can't update, such as a refilled or non-NIIMBOT roll, made the printer report error 0x14 and Thermalith stopped the job. Those tag errors no longer stop a print. (#29, from discussion #23)

## Changes

- **Each printer model gets the print sequence niimbluelib uses for it.** Thermalith now takes its model-to-sequence table from [niimbluelib](https://github.com/MultiMote/niimbluelib), and a model it doesn't list gets niimbluelib's rule based on the printer's protocol version. This moves the **K3**, **B21 Pro**, **C1** and **EP1C** to the newer sequence, the **B21S-C2B** to the D110 sequence, and the **D101** and **D110_M** to the B1 sequence (a D110_M reporting protocol 4 gets the newer one). The B1, B4, B3S and D11_H, which we test on, are unchanged. Thanks to MultiMote for pushing on this in #21.
- **Printer errors say what went wrong.** Instead of a bare code, a failed print now reads, for example, "error code 0x14 (couldn't write to the label roll's RFID tag - the roll may be third-party, refilled, or used up)". Thermalith now knows niimbluelib's full list of printer error codes.
- **Positions and sizes are 0.1 mm throughout.** Center H, Center V, auto-size text, scaling and newly inserted elements still rounded to whole millimetres, which showed on small labels. Auto-size text boxes in existing files tighten by up to 0.9 mm when opened, so centred text in them can move by up to about 0.5 mm.

## Fixes

- **Linux: emoji print instead of showing as squares.** Thermalith now uses its bundled monochrome Noto Emoji font when the system has none. Reported and fixed by BadgerCode (#24, #25).
- **Linux: opening or saving a file no longer crashes** when the desktop's file-dialog service refuses the request. Thermalith says so and uses its own file dialog from the next start. To use it from the start, set `THERMALITH_NO_PORTAL=1`. (#19)
- **Center V on small labels** left the selection flush against the top edge of a 12 mm cable label instead of centred.

## Known issues

- The B1 Pro fix and the new print sequences for the K3 and others have not been confirmed on those printers here. If one misbehaves, please open an issue with a connection log (Help > Connection Logging).
- With a design already on the canvas, loading a roll of a different size doesn't resize the label; only the printable-area guides change. The status line shows the roll size.
- macOS: a B1 Pro over Bluetooth may not connect (#26). We're looking into it.
- Data merge reads CSV files; Excel and database sources are planned for a later release.

## Downloads

Pick the build for your platform from the assets below:

- **Windows** - the `win-x64` `.zip`
- **Linux** - `linux-x64` (Intel or AMD) or `linux-arm64` (ARM, e.g. a Raspberry Pi), both `.tar.gz`
- **macOS** - `osx-arm64` (Apple Silicon) or `osx-x64` (Intel), both `.dmg`

The user manual PDF and the `Niimbot.Net` driver package (`.nupkg`) are attached too; the source is under "Source code" at the bottom of the release.

## First launch

The binaries are not code-signed yet, so the OS will warn on first launch:

- **macOS:** right-click the app and choose Open the first time, or run `xattr -dr com.apple.quarantine` on it.
- **Windows:** SmartScreen may warn. Choose More info, then Run anyway.
- **Linux:** `chmod +x` the extracted binary. If the printer port is denied, add your user to the `dialout` group.

Found a bug or want a model supported? Open an issue on the repo, and if it's a connection problem, attach a connection log (Help > Connection Logging).
